Publicar la Ruleta Gratis

Dos métodos sencillos para tener un enlace propio

Opción 1: Tiiny.host (Rápido, 1 clic sin cuentas)

  1. Guarda el código como index.html en tu PC.
  2. Entra a tiiny.host.
  3. Escribe un nombre para el enlace (ej: mi-amigo-secreto).
  4. Arrastra tu archivo index.html y haz clic en Publish.

Opción 2: GitHub Pages (100% Gratis para siempre)

  1. Entra a github.com y crea una cuenta gratuita.
  2. Crea un nuevo repositorio público llamado amigo-secreto.
  3. Sube el archivo index.html.
  4. Ve a Settings ➔ Pages, selecciona la rama main y guarda.
